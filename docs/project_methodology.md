# Project Methodology

## Step 1 - Collect Site Updates

The project begins with 60 synthetic network deployment updates.

Each update includes:

- Site ID
- Milestone
- Owner
- Planned date
- Completion percentage
- Status
- Dependency
- Issue
- Issue owner
- Requested decision

## Step 2 - Standardize Data

Site identifiers are normalized into a consistent naming convention.

## Step 3 - Validate Records

Records are checked for:

- Missing owners
- Missing dates
- Inconsistent site IDs
- Overdue milestones

## Step 4 - Calculate Portfolio Metrics

The project calculates:

- Total updates
- Unique sites
- Average completion
- Completed milestones
- Overdue items
- Missing owners
- Missing dates
- Open issues

## Step 5 - Create Dashboard Views

Three reporting datasets are created:

1. Progress Dashboard
2. Risk Dashboard
3. Upcoming Work Dashboard

## Step 6 - Reconcile Data

Raw and processed record counts are compared to confirm no updates were lost during processing.

## Step 7 - Prepare Stakeholder Reporting

The project produces:

- Excel portfolio workbook
- Power BI-ready CSV datasets
- Weekly PowerPoint status deck

## Step 8 - Support Decisions

The final reports highlight:

- Dependencies
- Risks
- Issue owners
- Upcoming work
- Decisions needed from stakeholders
