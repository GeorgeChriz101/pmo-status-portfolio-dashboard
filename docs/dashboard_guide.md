# Dashboard Guide

The project creates three main dashboard views.

## Progress Dashboard

Shows progress across network sites.

Metrics include:

- Average completion percentage
- Completed milestones
- Total updates per site

The dashboard helps answer:

Which sites are progressing well?

Which sites need additional attention?

## Risk Dashboard

Highlights project risks and exceptions.

Includes:

- Overdue work
- Open issues
- Issue owners
- Missing owners
- Missing dates
- Requested stakeholder decisions

## Upcoming Work Dashboard

Shows future planned activities.

Includes:

- Site
- Milestone
- Owner
- Planned date
- Dependency
- Status

## Power BI

The following files are designed to be imported into Power BI:

- dashboard_progress.csv
- dashboard_risks.csv
- dashboard_upcoming_work.csv

These datasets can be used to create visual portfolio reporting.
