# Reconciliation Guide

## Purpose

Reconciliation confirms that the portfolio reporting process did not accidentally lose project updates during processing.

## Source Count

The raw dataset contains 60 site updates.

## Processed Count

The cleaned dataset should also contain 60 updates.

## Expected Result

Raw Records = 60

Processed Records = 60

Difference = 0

Reconciled = True

## Why This Matters

PMO dashboards depend on accurate totals.

If records disappear during data preparation, completion percentages, risk counts, and portfolio metrics may become inaccurate.

Reconciliation provides a simple control to verify that the reporting dataset is complete.
